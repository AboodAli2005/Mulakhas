# تطبيق ملخص للموبايل (Flutter Mobile App) 📱

تطبيق موبايل متكامل واحترافي لمنصة **ملخص (Academic Library)** مبني باستخدام **Flutter** و **Riverpod**، ويتصل مباشرة وبشكل حي بنفس **ASP.NET Core Web API** ونفس قاعدة البيانات المستخدمة في مشروع الويب الحالي.

---

## 🌟 مميزات التطبيق

1. **تصميم احترافي ومخصص للموبايل:**
   - واجهات متناسقة وعصرية تدعم اللغة العربية بالكامل (**RTL**) وخط **Cairo** الأصيل المدمج في المشروع.
   - دعم الوضعين الفاتح والداكن (**Dark & Light Mode**) مع حفظ التفضيل تلقائياً.
   - شريط تنقل سفلي مرن وسريع (**Bottom Navigation Bar**).
   - مسار تصفح سريع (**Breadcrumbs**) للتبديل السريع بين التخصصات والسنوات والفصول.

2. **التكامل مع الـ Backend الفعلي (ASP.NET API):**
   - **بدون أي Mock Data** - يتصل مباشرة بالخادم: `https://aug-backpack.runasp.net/api/v1`.
   - استخراج وتصفح التخصصات (`/majors`)، السنوات الدراسية (`/levels`)، الفصول (`/semesters`)، والمواد (`/subjects`).
   - عرض وتصفية المذكرات (`/summaries`) والمحاضرات (`/lectures`).
   - بحث فوري مع ميزة التهدئة الزمنية (**Debounce 500ms**) لتقليل استهلاك السيرفر وحظر الطلبات المتكررة.

3. **التعامل مع الملفات والـ PDF:**
   - استخراج الرابط الكامل للملفات سواء كانت مخزنة على السيرفر المحلي أو روابط Google Drive.
   - فتح المستندات مباشرة عبر المشغل الخارجي والتطبيقات المتخصصة.
   - إمكانية تنزيل الملفات محلياً وحفظها في الذاكرة للرجوع إليها بدون إنترنت مع شريط تقدم مباشر (**Progress Bar**).
   - إمكانية مشاركة روابط المذكرات مع الزملاء.

4. **المفضلة والمحفوظات المحلية:**
   - إمكانية تمييز أي ملخص أو محاضرة بنجمة/إشارة مرجعية للوصول إليها مباشرة من تبويب المفضلة.
   - حفظ التفضيلات والمسار الأكاديمي محلياً باستخدام `SharedPreferences`.

## 🏗️ هيكلية المشروع (Clean Architecture)

```text
mulakhas_mobile/
├── assets/
│   ├── fonts/               # خطوط Cairo المدمجة
│   └── images/              # شعار التطبيق وأيقونة التبويب الأصلية
├── lib/
│   ├── core/
│   │   ├── config/          # إعدادات الـ API والروابط الأساسية (AppConfig)
│   │   ├── constants/       # أسماء الـ Endpoints وألوان الهوية البصرية
│   │   ├── network/         # عميل Dio ومعالجة أخطاء الشبكة والـ Interceptors
│   │   ├── theme/           # ثيمات التطبيق (Dark & Light)
│   │   └── utils/           # أدوات Debounce وفتح الروابط
│   ├── models/              # نماذج البيانات المتوافقة 100% مع DTOs الـ ASP.NET
│   │   ├── lookup_dto.dart  # للتخصصات والمستويات والفصول
│   │   ├── subject_dto.dart # للمواد الدراسية
│   │   ├── summary_dto.dart # للملخصات والمحاضرات
│   │   └── api_response.dart# غلاف الاستجابات والـ Pagination
│   ├── services/            # استدعاءات الـ API والتخزين والتنزيل
│   │   ├── api_service.dart
│   │   ├── storage_service.dart
│   │   └── download_service.dart
│   ├── repositories/        # طبقة عزل المنطق ومصادر البيانات
│   ├── providers/           # إدارة الحالة باستخدام Riverpod
│   ├── widgets/             # بطاقات وعناصر الواجهة القابلة لإعادة الاستخدام
│   ├── screens/             # الشاشات الرئيسية للتطبيق
│   │   ├── splash/          # شاشة البداية المتحركة
│   │   ├── home/            # الصفحة الرئيسية واستعراض المنصة
│   │   ├── selection/       # شاشات اختيار التخصص والمستوى والفصل
│   │   ├── materials/       # شاشة عرض المواد وتفاصيل المستندات
│   │   ├── search/          # شاشة البحث الشامل
│   │   ├── favorites/       # شاشة المذكرات المحفوظة
│   │   └── about/           # عن المنصة وإعدادات التطبيق
│   └── main.dart            # نقطة البداية وإعدادات Riverpod والـ RTL
└── pubspec.yaml             # تبعيات المشروع
```

## ⚙️ متطلبات التشغيل

1. تثبيت **Flutter SDK** (الإصدار 3.0.0 أو أحدث).
2. فتح موجه الأوامر في مجلد `mulakhas_mobile`:
   ```bash
   cd mulakhas_mobile
   flutter pub get
   flutter run
   ```

## 🔧 إعدادات الـ API ونقل التطبيق إلى Production

- يتم التحكم في رابط الخادم بالكامل من ملف واحد مركزي:
  `lib/core/config/app_config.dart`
  ```dart
  static const String apiBaseUrl = 'https://aug-backpack.runasp.net/api/v1';
  static const String fileServerUrl = 'https://aug-backpack.runasp.net';
  ```
- لتغيير الخادم إلى السيرفر المحلي أو سيرفر إنتاجي جديد، قم فقط بتعديل هذين المتغيرين دون لمس بقية الكود.
